Задание 2. Middleware для логирования в Go: фактический вывод
===========================================================

Дата проверки: 2026-10-06
Полный лог сервера: server.log

$ go run ./task2
Gin-сервис слушает http://localhost:8080

$ curl http://127.0.0.1:8080/ping
{"message":"pong"}

$ curl http://127.0.0.1:8080/hello/World
{"hello":"World"}

Серверный лог (server.log):
2026/10/06 17:55:06 Gin-сервис слушает http://localhost:8080
2026/10/06 17:55:08 [GIN] GET /ping -> 200 (0s)
2026/10/06 17:55:08 [GIN] GET /hello/World -> 200 (0s)

Каждая строка лога формируется middleware LoggerMiddleware: метод, путь,
код ответа и время обработки запроса.
